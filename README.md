made using cLion C++17

methods:
isSorted(vector) return true if vector is sorted, false if not
bubbleSort(vector) bubble sorts a vector
selectionSort(vector) selection sorts a vector
insertionSort(vector) insertion sorts a vector
quickSort(vector) quick sorts a vector
randNums(n) generates a random vector with n elements varying to 0 to n-1
sortedNums(n) generates a sorted vector with n elements from 0 to n-1
reverseSortedNums(n) generates a reverse sorted vector with n elements from n-1 to 0
bubbleTime(vector) calculates the average runtime of 2 bubbleSorts on copies of the same vector in microseconds
selectionTime(vector) calculates the average runtime of 2 selectionSorts on copies of the same vector in microseconds
insertionTime(vector) calculates the average runtime of 2 insertionSorts on copies of the same vector in microseconds
quickTime(vector) calculates the average runtime of 2 quickSorts on copies of the same vector in microseconds
